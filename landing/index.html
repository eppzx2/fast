02 / OPERATING MODEL

From signal to
security decision.

The platform separates collection, detection and analyst-owned state so a raw event can become a traceable investigation.

01

Collect

Pull fresh indicators from public and authenticated threat feeds.

02

Normalize

Unify provider formats, timestamps, tags and confidence across feeds.

03

Observe

Wazuh Agents deliver endpoint and security telemetry to the Manager.

04

Correlate

FAST rules turn repeated or suspicious behavior into high-value detections.

05

Investigate

Analysts review context, MITRE mapping, notes, assignee and incident state.
